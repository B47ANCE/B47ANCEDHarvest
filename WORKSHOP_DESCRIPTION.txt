[h1]B47ANCE'd Harvest[/h1]

Agriculture, crop inspection, field planning, and farming-system infrastructure for theWorks ecosystem.

B47ANCE'd Harvest normalizes vanilla and compatible crops while exposing bounded field and irrigation-demand information for future agricultural gameplay.

[b]Mod Version: 0.9.2[/b]

[b]MP testing build - dedicated multiplayer NOT TESTED[/b]

[b]Development Status[/b]

This is an API foundation under active development, not yet a standalone farming overhaul.

[h2]Current Features[/h2]
[list]
[*]Vanilla and third-party crop-provider normalization
[*]Cursor-paged field inspection capped at 1,024 candidates per call
[*]Crop and field summaries that exclude empty furrows and report rejected candidates
[*]Pure, non-mutating irrigation-demand planning from live crop state
[*]Authoritative crop-side irrigation with bounded uses, readback validation, and explicit partial/unknown effect receipts
[*]Seasonal guidance respects native sandbox configuration and validates calendar/month data
[*]Provider isolation and public extension APIs
[*]Bounded nearby-crop developer inspector using the vanilla farming-system lookup
[/list]

[h2]Ecosystem Integration[/h2]
[list]
[*]Adapts vanilla-owned crops and supplies field-management and irrigation APIs
[*]Exposes irrigation demand for waterWorks without owning water infrastructure
[*]Will consume groundWorks terrain state without owning generic ground transformation
[*]Will integrate animalWorks draft-animal implements without owning animal behavior
[*]Has no required mod dependencies in the current foundation
[/list]

[h2]Upcoming Features[/h2]
[list]
[*]Soil and crop interaction, fertility, amendments, and field management
[*]Transactional coupling between waterWorks supply and B47ANCE'd Harvest crop application
[*]Implements, machinery, orchards, fencing, and multiplayer validation
[/list]

[h2]Compatibility and Configuration[/h2]

Build 42 API foundation. Offline Lua 5.4/5.1 fixtures pass; SP and dedicated multiplayer are NOT TESTED. Seasonal advice respects the server's native PlantGrowingSeasons setting. The base module has no hard mod dependencies; seasonal advice requires the optional weatherWorks calendar and an explicit map context.

[url=https://github.com/B47ANCE/B47ANCEDHarvest]GitHub — Source Code & Issues[/url]

[h2]Known Limitations[/h2]

This is a framework foundation with console diagnostics, not a standalone farming overhaul. There is no player-facing field-management UI or automatic irrigation loop. Water-source withdrawal and crop application are not an atomic transaction; partial/unknown provider effects require reconciliation. Native calendar, save/load, join/rejoin and server restart validation remain pending. G7 and stable-release G8 remain blocked.
