description=
description=This is an API foundation under active development, not yet a standalone farming overhaul.
description=
description=[h2]Current Features[/h2]
description=[list]
description=[*]Vanilla and third-party crop-provider normalization
description=[*]Cursor-paged field inspection capped at 1,024 candidates per call
description=[*]Crop and field summaries that exclude empty furrows and report rejected candidates
description=[*]Pure, non-mutating irrigation-demand planning from live crop state
description=[*]Authoritative crop-side irrigation with bounded uses, readback validation, and explicit partial/unknown effect receipts
description=[*]Seasonal guidance respects native sandbox configuration and validates calendar/month data
description=[*]Provider isolation and public extension APIs
description=[*]Bounded nearby-crop developer inspector using the vanilla farming-system lookup
description=[/list]
description=
description=[h2]Ecosystem Integration[/h2]
description=[list]
description=[*]Adapts vanilla-owned crops and supplies field-management and irrigation APIs
description=[*]Exposes irrigation demand for waterWorks without owning water infrastructure
description=[*]Will consume groundWorks terrain state without owning generic ground transformation
description=[*]Will integrate animalWorks draft-animal implements without owning animal behavior
description=[*]Has no required mod dependencies in the current foundation
description=[/list]
description=
description=[h2]Upcoming Features[/h2]
description=[list]
description=[*]Soil and crop interaction, fertility, amendments, and field management
description=[*]Transactional coupling between waterWorks supply and B47ANCE'd Harvest crop application
description=[*]Implements, machinery, orchards, fencing, and multiplayer validation
description=[/list]
description=
description=[h2]Compatibility and Configuration[/h2]
description=
description=Build 42 API foundation. Offline Lua 5.4/5.1 fixtures pass; SP and dedicated multiplayer are NOT TESTED. Seasonal advice respects the server's native PlantGrowingSeasons setting. The base module has no hard mod dependencies; seasonal advice requires the optional weatherWorks calendar and an explicit map context.

description=[h2]Known Limitations[/h2]
description=
description=This is a framework foundation with console diagnostics, not a standalone farming overhaul. There is no player-facing field-management UI or automatic irrigation loop. Water-source withdrawal and crop application are not an atomic transaction; partial/unknown provider effects require reconciliation. Native calendar, save/load, join/rejoin and server restart validation remain pending. G7 and stable-release G8 remain blocked.
